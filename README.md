- `index.html` — simple page: centered logo, Contact, Instagram (handle later)
- `logo.png` — full lockup, transparent background (from `logo.jpg`)
- `logo-mark.png` — circle only, transparent, used as favicon
- `favicon.svg`
- Contact: `claeys.vereecken20@hotmail.com`
- Instagram: not linked yet. Set `data-instagram` on the Instagram button in `index.html` to the profile name (no @).

## Not claimed on the page

No product list, prices, ages, or safety marks. Those wait until the shop exists.

## Deploy later (Cloudflare Pages)

Domain is already on Cloudflare nameservers. No DNS records yet, so the site is not public.

1. Workers & Pages → Create → Pages → Upload assets.
2. Upload this folder.
3. Custom domain: `d3kids.com` and `www.d3kids.com`.

Do not publish until the Instagram handle is filled in, unless you want that button inactive.
